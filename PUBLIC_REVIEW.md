# Public code review snapshot

This is a sanitized source snapshot for code review, not a deployment artifact. Real environment files, customer and order data, backups, operational handoffs, build outputs, and dependencies are excluded. Deployment addresses and sensitive-looking values (including some synthetic test literals) have been replaced. Tests and examples may require coordinated local-only replacements before they can run. Do not connect this snapshot to production services.

`.env.example` is a synthetic starting point only. Use fresh local credentials and isolated local services. The original README refers to internal documents omitted from this public snapshot. Each branch is an independently assembled review snapshot; the formal inspection, customer sharing, search candidate, and review-access branches have different baselines and are not claims of production deployment or end-to-end validation.
